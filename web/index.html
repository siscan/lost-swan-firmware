Remaining

—

The countdown is a deadline held by the display, not a ticking timer: a power cycle resumes it, and a terminal prop on MQTT renders the same target.

Mode

Countdown switches to an idle 108:00 until it is started. MESSAGE needs a message to have been set first.

Message

Each picker offers only what that column's drum carries — column 5's ring is a different part number and its glyph set differs.

Presets

Countdown

Columns

Nudge until the blank card hangs flat against the bezel lip and the next card is fully retained, then SAVE. Rotation is forward only, so a nudge never reverses the drum.

Index walk

Steps a column through its ring so the expected character can be checked against the drum. On column 5 a digit legitimately appears at two slots 25 apart — that is the double block, not a fault (docs/BRINGUP.md).

Test spin

Open loop: the displayed index becomes unknown, and the active mode moves the column back to the current frame when the spin ends.

System

Columns

real drives the hardware. sim runs the same control core against a modelled drum — real timing, real Hall edges, real homing — so everything above the axis layer is exercised with no mechanism attached. disabled parks the column on blank and leaves it out of every frame: the mode keeps running and the display carries a hole. Set by you, never inferred — a fault never disables a column, and it stays a fault until you clear it.

Maintenance

Stops frame scheduling, suspends the modes, and turns off automatic re-homing. Manual commands still work, so a suspect column can be driven by hand from Calibrate. It survives a reboot — pulling power mid-repair must not restart a countdown on top of your hands. Leaving it re-arms everything and re-homes all five.

Clock

Divisors of 60 only — at 7 the flooring would step 56 → 0 across the hour and the display would jump. The figures beside each choice are measured on the device by walking a whole day through the real renderer against the loaded ring, not looked up, so they are exact and they follow a ring upload. Note 12 minutes costs more than 10 or 15: at 10 the ones-of-minutes digit is always 0, so column 5 never moves.

Countdown

Every mode holds MMM:00 for the bulk of the run — the seconds columns are frozen and cost nothing — and only changes resolution once the run has seconds live left. That instant is also the 4-minute cue, so the display waking and the warning sound are one moment.

Reveal frame

The five glyphs the columns land on after the alarm spin. Set by NAME, never by index — the same index is a different character on column 5.

Message

Changes above apply live; this persists them.

Ring

The upload is validated into a staging table first; the running table is swapped in by the modes task only if it parses, has exactly 50 slots and can render every role its column will be asked for. A bad or truncated upload leaves the display untouched.
