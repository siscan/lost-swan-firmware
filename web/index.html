Remaining

—

The countdown is a deadline held by the display, not a ticking timer: a power cycle resumes it, and a terminal prop on MQTT renders the same target.

Mode

Countdown switches to an idle 108:00 until it is started. MESSAGE needs a message to have been set first.

Message

Each picker offers only what that column's drum carries — column 5's ring is a different part number and its glyph set differs.

Presets

A preset takes the display over, including from a running countdown — the deadline keeps running underneath and the cues still fire, but the columns stop showing it until the mode is set again.

System

Log and journal

— 

  
The log is the last few kilobytes the firmware printed,
     in RAM, lost at power-off — a byte budget rather than a line count,
     and it says how many lines were evicted so “the log starts
     here” is a fact. The journal is permanent and much shorter:
     countdowns with who set them, faults and recoveries, mode changes, and one
     line per boot with the reset reason. It survives power loss and is the
     display's actual history.







  
Columns

  
real drives the hardware. sim runs the same
     control core against a modelled drum — real timing, real Hall edges, real
     homing — so everything above the axis layer is exercised with no mechanism
     attached. disabled parks the column on blank and leaves it out of
     every frame: the mode keeps running and the display carries a hole. Set by
     you, never inferred — a fault never disables a column, and it stays a fault
     until you clear it.

  

  

    
    
    
  


  
Maintenance

  
Stops frame scheduling, suspends the modes, and turns off
     automatic re-homing. Manual commands still work, so a suspect column can be
     driven by hand from Calibrate. It survives a reboot — pulling power
     mid-repair must not restart a countdown on top of your hands. Leaving it
     re-arms everything and re-homes all five.

  

    
    
  


  
Clock

  

    
    
  

  

    
    
  

  

    
    
    Takes effect at the next boot — SNTP is started once,
      early. The clock free-runs without it; drift is seconds a day.
  

  

    
    
    
  

  
Divisors of 60 only — at 7 the flooring would step 56 → 0
     across the hour and the display would jump. The figures beside each choice
     are measured on the device by walking a whole day through the real
     renderer against the loaded ring, not looked up, so they are exact and
     they follow a ring upload. Note 12 minutes costs more than 10
     or 15: at 10 the ones-of-minutes digit is always 0, so column 5
     never moves.

  


  
Countdown

  
Every mode holds MMM:00 for the bulk of the run — the
     seconds columns are frozen and cost nothing — and only changes resolution
     once the run has seconds live left. That instant is also the
     4-minute cue, so the display waking and the warning sound are one moment.

  

    
    
  

  

    
    
    
  

  

  

    
    
    
    
  

  
The alarm loops for at most alarm loop seconds —
     unbounded would mean a display in an empty house screaming until somebody
     comes home. failure timeout of 0 means the reveal frame stays up
     until the mode is changed.

  

    
  

  

    
  


  
Reveal frame

  
The five glyphs the columns land on after the alarm spin. Set by
     NAME, never by index — the same index is a different character on column 5.

  


  
Message

  

    
    
  


  

    
    Clock, countdown, reveal and message settings apply live;
      this persists them. Column modes, maintenance, WiFi, MQTT and audio are
      not in this — each writes NVS the moment you change it.
  


  
Ring

  

    
  

  

    
    
  

  
The upload is validated into a staging table first; the running
     table is swapped in by the modes task only if it parses, has exactly 50
     slots and can render every role its column will be asked for. A bad or
     truncated upload leaves the display untouched.


  
WiFi

  
—

  

    
    
    
    
    
  

  
The display keeps running as a clock while it joins, and stays
     on the network it is on until the new one accepts it — so getting this
     wrong costs you a retry, not access. A free-running clock survives a WiFi
     outage; only SNTP re-syncs need the network.

  

    
    
  

  
The portal is an open access point plus a captive sign-in page,
     for when the SSID has changed and there is no other way in. It never starts
     itself — a router rebooting must not put a wall display into AP mode.
     The access point follows the station's channel, so on a 5 GHz network
     that is where it appears.


  
MQTT and Home Assistant

  
—

  
—

  

    
  

  

    
    
  

  

    
    
    
    
  

  
The password box starts empty every time and leaving it
     empty keeps the stored password — it is never sent back to this
     page, by design, because the state document does not carry it. Everything
     else here shows what is actually stored, so clearing the user box does
     clear the user.

  

    
    
    
    
  

  

    
  

  
The terminal prop is a peer, not a part of this display:
     it publishes its own presence on swan/prop/terminal (retained,
     with a last will) and this display only reads it. Nothing here can turn the
     prop on or off, and the prop is never required — the display is a
     complete standalone clock without one.

  
Anyone who can publish to your broker can drive this
     display — every command this page can send, including reboot,
     maintenance and the OTA controls. That is deliberate (spec §10.3): MQTT
     is the canonical external API and a second credential in the firmware would
     break Home Assistant discovery for the entities most worth having. Scope the
     broker's ACL, not the firmware. Turning MQTT off retracts the discovery
     entities while still connected; there is no way to say it afterwards.


  
Audio

  

    
    
    
  

  
The scale is perceptual rather than linear — a linear one
     spends its top half sounding identical. There is no hardware volume; this is
     software gain before the I2S write.

  

    
    
    
    
    
    
  

  
Quiet hours wrap midnight. They silence the countdown cues; an
     explicit PLAY below ignores them, because somebody testing the speaker
     should not be met with silence that looks like a broken amplifier.


  
Cues

  

  
The five that ship are synthesized placeholders, not the
     show's sounds. Upload a 16-bit mono PCM WAV (8–32 kHz, up to
     192 KB) to replace one with no reflash: it is parsed in full, written
     to a temp file and renamed over the old one only once it parses, so a
     truncated upload leaves the previous cue playable. Check the duration
     after uploading — a cue that is present, valid and two
     milliseconds long looks identical to a working one from every other
     reading.







  
Running image

  

  

    This image has not confirmed itself yet. It is running on trial: if it
    does not reach the end of app_main, load its config, tick the
    modes and motion tasks and start the web server within 120 seconds of
    boot, the bootloader rolls back to the other slot. Confirm once you are
    satisfied it works — and note that rebooting while it is pending
    is itself what triggers a rollback.
    

      
      
    

  


  
Upload firmware

  
The image is written to the other slot and the display reboots
     into it. Motion is held for the duration — all five columns must be
     idle, or maintenance on — and the upload is bounded (120 s total,
     a 10 s stall limit, a throughput floor), because until it finishes the
     clock, the cues and this page are all waiting on it.

  

    
    
  

  

    
  

  
Two refusals are soft, and both are worth reading before you
     override them. An image built for the other board passes every check
     the bootloader makes and then drives STEP on the wrong pins. A release
     image onto a display with simulated columns comes back with five columns
     it cannot honour, faults them all and drops EN — surviving state the
     new image cannot honour is worse than state that did not survive. A moving
     drum is refused regardless, and that one cannot be forced.
