# Swan patch trigram ring — authoritative sequence

**Rule (Lostpedia, DHARMA Initiative page):** classic station logos use the
**Later Heaven (King Wen) bagua**, with every trigram **inverted
inside-to-outside** from its normal orientation. Concretely: in a normal
bagua the trigram's bottom line faces the centre; on the DHARMA logos the
**bottom line faces OUTWARD — the trigram's top line is the innermost bar.**

Correction to the request as phrased: the 90° quarter-turn is not the
Earlier Heaven arrangement — Lostpedia attributes it to the ARG-era
modernised logo ("the arrangement of the standard logo was turned 90 degrees
clockwise"). The classic station ring is the un-rotated Later Heaven below.

1 = solid (yang), 0 = broken (yin).
`canonical` reads the trigram bottom→top; `render` reads INNER→OUTER bar.

| # clockwise from top | trigram | element | canonical b→t | render inner→outer |
|---|---|---|---|---|
| 1 (top) | Li ☲ | fire | 1 0 1 | **1 0 1** |
| 2 | Kun ☷ | earth | 0 0 0 | **0 0 0** |
| 3 (right) | Dui ☱ | lake | 1 1 0 | **0 1 1** |
| 4 | Qian ☰ | heaven | 1 1 1 | **1 1 1** |
| 5 (bottom) | Kan ☵ | water | 0 1 0 | **0 1 0** |
| 6 | Gen ☶ | mountain | 0 0 1 | **1 0 0** |
| 7 (left) | Zhen ☳ | thunder | 1 0 0 | **0 0 1** |
| 8 | Xun ☴ | wind | 0 1 1 | **1 1 0** |

Note: four trigrams (Li, Kun, Qian, Kan) are palindromes, so the inversion
is invisible on them — only Dui, Gen, Zhen, Xun visibly flip. That is why
mis-drawn fan versions are common; check those four against the table.
